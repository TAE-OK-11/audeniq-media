# Models

`eng.traineddata` and `kor.traineddata` are the `tessdata_fast` LSTM models
(<https://github.com/tesseract-ocr/tessdata_fast>, Apache-2.0, © Google Inc.)
as packaged by Debian/Ubuntu `tesseract-ocr-eng` / `tesseract-ocr-kor`
1:4.1.0. They are the models the Audeniq backend ran with Tesseract; they
are embedded so the OCR needs no system packages.
